2026-11-02 · Master Assistant and Michael Lane Edition · public build 2026110204
  • Published the integrated Lemon Master Assistant: mastering EQ, dynamic EQ, multiband compression, stereo imaging and maximizer, with dedicated master controls and settings saved in projects. The native engine is included in installations and automatic updates.
  • Added the channel-strip mixer view, hosting original Waves plugin interfaces above analog-style faders, with improved fitting, section-aligned paging and Abbey Road TG12345 paging. Waves is the currently tested focus; third-party plugins are not included.
  • Added routing by dragging channels onto hosted plugin panels and polished mixer spacing, metal separators, illuminated polarity/swap controls, pan and stereo separation controls.
  • Added tempo undo, selected-pattern following, sampler file-dialog previews and editable shortcuts for common commands.
  • Added manual audio warp markers with project persistence, undo and rendering while preserving the source and pitch.
  • Improved Parametric EQ 2 HQ mode and parameter smoothing; preserved rejected imported plugin state for recovery without claiming universal FLP plugin-setting compatibility.
  • Added the Lemon Wave wavetable instrument foundation and factory presets.
  • Identified this edition consistently as Michael Lane Edition and linked its public source fork while preserving original Lemon Studio and dependency credits.
  • Added the shared website and in-app Change Log and improved narrow community-tab labels.
  • Known issues remain: Auto-Tune ARA compatibility and Melodyne transport behavior. Linux packages are compiled; Linux audio/runtime testing has not been performed.
2026-11-02 · Lemon Chop, pitch and workflow · public build 2026110203
  • Added Lemon Chop, a separate slicing instrument with cue pads, automatic slicing, editable cue regions, pad names/favorites, reverse, pitch/stretch controls and undo/redo.
  • Integrated optional local stem separation into Chop, with selectable stem mixes and source-region export; saved Chop state reopens with the project.
  • Added Chop to Instruments / Sampler for existing and new profiles without duplicate entries after rescans.
  • Fixed loading audio into Chop from the sample browser, plugin frame and Explorer drops; reloading the same source refreshes analysis.
  • Added a searchable visual plugin picker with favorites, real editor previews and instrument/effect filtering appropriate to the destination.
  • Added cancellable automatic plugin preview capture on Windows, with isolated helpers, progress, timeouts and cached results.
  • Simplified channel rack context menus and added direct access to the instrument picker.
  • Moved Global Pitch to compact channel rack controls; added per-channel pitch ranges and a global-follow switch that preserves pitch when toggled.
  • Added master tape-style Varispeed, changing pitch and duration together for the complete mix and exports.
  • Added reversible channel Consolidate / Bounce to Audio, including an effects-rendered option and a keep-mixer-live option; preserves the muted original and provides undo.
  • Added actual waveform previews for bounced audio in the channel rack.
  • Added Scale Notes Only to the piano roll for all 22 scales and 12 roots; out-of-scale MIDI is preserved and returns when filtering is disabled.
  • Fixed playback continuity while trimming audio clips and made resize edges take priority over clip-body actions.
  • Fixed non-Windows compilation of the preview helper. Windows, Linux x64 and Apple-silicon Mac packages were published as 2026110203; preparation build 2026110202 was not published.
